Profile

From biological complexity to inspectable evidence.

I build analysis workflows that connect a biological question to data, models, visual evidence, and a result that another researcher can understand and reproduce.

My current work spans protein interaction networks, molecular dynamics, domain characterization, in silico modelling, and numerical optimization. The common thread is a practical one: make complex systems easier to interrogate without losing the scientific context behind them.

Approach

A research workflow built for traceability.

01

Frame the question

Define the biological system, the useful evidence, and the limits of the analysis.

02

Build the model

Translate sequences, structures, networks, or observations into computational objects.

03

Interrogate the data

Use statistical, graph, and machine-learning methods to test patterns and candidates.

04

Make evidence legible

Package code, figures, assumptions, and reports so the result can be inspected.
